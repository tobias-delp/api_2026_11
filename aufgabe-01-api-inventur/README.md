# Aufgabe 01: API-Inventur & Live-Röntgenblick

## Auftrag
1. Öffne im Browser eine bekannte Web-App (z. B. Wetterseite, Online-Shop, GitHub) und starte die **DevTools (`F12` → Tab „Netzwerk“ → Filter `Fetch/XHR`)**. Beobachte, welche API-Requests im Hintergrund ausgelöst werden.
2. Wähle **drei digitale Produkte** aus deinem Alltag und überlege, welche APIs dahinterstecken.
3. Dokumentiere für jedes Produkt **Client, Server, Ressource und Zweck** in `api-inventur.md`.

## Ergebnis
Ausgefüllte `api-inventur.md` als Diskussionsgrundlage im Plenum.

# Aufgabe 02: Todo-Datenmodell & erster API-Vertrag

## Auftrag
1. Analysiere die Beispieldaten in `todos.json` und ergänze zwei eigene Todos.
2. Dokumentiere die Felder, Datentypen und Pflichtfelder in `datenmodell.md`.
3. Entwirf in `api-vertrag.md` den fachlichen API-Vertrag für Version 1 der Todo-API auf Basis von **CRUD** (*Read All, Read One, Create, Update, Delete*) inklusive mindestens **zwei fachlicher Fehlerfälle**.

## Ergebnis
Konsistente `todos.json`, ausgefüllte `datenmodell.md` und ein prüfbarer `api-vertrag.md` — in UE 2 übersetzen wir diesen Vertrag auf HTTP-Methoden und Statuscodes.
